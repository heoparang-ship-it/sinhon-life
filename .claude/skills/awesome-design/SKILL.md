# Awesome Design Resources

A curated catalog of design resources, sourced from
[gztchan/awesome-design](https://github.com/gztchan/awesome-design). Use it to
recommend concrete tools, assets, and references for design work.

## How to use

1. Identify which category the user's need maps to (see list below).
2. Open `resources.md` in this skill directory and pull the most relevant
   entries for that category.
3. Recommend a short, ranked shortlist (not the whole dump). Prefer free or
   freemium options unless the user wants paid/pro tools.
4. Always cite the resource name **and** its URL so the user can click through.

## Categories (full link lists live in `resources.md`)

**Get things done**
- **Stock** — free image / video libraries (Unsplash, Pexels, Pixabay…)
- **Color** — palette generators & inspiration (Coolors, Adobe Color…)
- **Icon and Logo** — icon sets & logo inspiration
- **Typography** — fonts & type foundries (Google Fonts…)
- **Toolkit** — design software (Figma, Sketch, Adobe CC…)
- **Prototyping** — interactive tools (InVision, Marvel, Framer…)
- **Mockup** — device & presentation mockups
- **User Testing** — research & feedback platforms

**Concepts**
- **Read and Digest** — design blogs & publications
- **Styleguide and Branding** — brand identity references
- **Tutorial** — learning platforms
- **Book** — recommended design reading
- **Award** — competitions & recognition
- **Conference and Festival** — industry events
- **Podcast** — design audio shows
- **Community** — portfolio platforms (Dribbble, Behance, Medium…)

For the complete, link-by-link lists, read `resources.md` in this directory.
