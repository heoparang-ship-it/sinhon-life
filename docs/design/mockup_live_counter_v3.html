동작 요약 — 삼쩜삼 메커니즘 이식
  • 인증 → 질문: 홈택스가 없으니 질문 3개를 인증 자리에. 단, 답마다 숫자가 실제로 차오름(클릭해서 확인).
  • 평균에서 시작: 150만원으로 시작 → 내 답으로 상승. "내가 평균보다 많네"를 직접 목격 = 내 돈 각인.
  • 증분 가시화: 옵션마다 +150만 / +40만 떠오르고 카운터가 튕김(bump). 데이터가 계산하는 마법 모사.
  • 정직한 규칙: 각 가산액은 검증된 정책 금액 기반(천원주택·보증료40·산후150·청년이자). 과장 아님.
  • 결과 = 환급내역: 삼쩜삼 "환급 내역"처럼, 내 금액의 근거 정책 목록 + 진짜 마감 카운트다운.
  • 성공보수 평행: 보기 무료 / Phase2 송객 수수료 = 삼쩜삼 환급 성공 시 수수료와 동일 신뢰구조.
