심리 트리거 해설 — 왜 "빨리 해야겠다"가 되는가

각 화면 요소를 행동경제학 원리에 1:1로 매핑했습니다. 모든 트리거는 실제 사실 기반(진짜 마감일·진짜 출생연도 조건)이라 과장이 아닙니다.

Trigger 01 · 즉시성
⚡일하기 전에 숫자부터
Frame A · 착지 0초
삼쩜삼의 본질. 사용자가 아무 노력도 하기 전에 "190만원"이 카운팅되며 뜬다. 노력→보상이 아니라 보상 미리보기→노력 순서. 진입 마찰을 보상 기대가 압도.
Trigger 02 · 손실 회피
⏳"안 챙기면 0원, 사라진다"
Frame A · 손실 바
사람은 같은 금액도 얻는 기쁨보다 잃는 고통을 2배로 느낌(전망이론). "받으세요"가 아니라 "이미 당신 몫인데 사라진다"로 프레임 → 행동 압력 급증.
Trigger 03 · 구체화
✈️다낭 2명 · 냉장고 1대
Frame A · 등가 환산
"190만원"은 추상적. 다낭 허니문 2명으로 바꾸면 뇌가 즉시 그림을 그림(심상화). 숫자에 감정과 욕망을 붙여 행동 동기를 키움.
Trigger 04 · 사회적 증명
🔴실시간 "방금 230만원 확인"
Frame A · LIVE 티커
"오늘 1,204명"은 밴드왜건 + FOMO. 남들이 이미 챙기고 있다는 신호가 "나만 안 하면 손해"를 만듦. 외로움 제거(미션)와도 정합.
Trigger 05 · 자이가르닉
🔓흐릿하게 이미 보이는 금액
Frame B · 잠금 해제
정확한 금액(2,340,000)을 블러로 미리 보여줌. 미완성 정보는 뇌에 긴장을 남겨 완성하고 싶게 만듦(자이가르닉 효과). "1개만 더"가 거부하기 어려움.
Trigger 06 · 진행 부여 효과
📊이미 80% 와 있음
Frame B · 진행바
처음부터 80% 채워진 진행바를 보여주면 "거의 다 왔는데 그만두면 아깝다"(목표 구배 효과). 0%에서 시작하는 것보다 완료율이 크게 오름.
Trigger 07 · 희소·마감
⏱️천원주택 모집 D-12 카운트다운
Frame C · 마감 배너
진짜 마감일(모집 공고)을 초 단위 카운트다운으로. 시간 압박은 숙고를 줄이고 즉시 행동을 부름. "다음 공고까지 기다려야"가 손실을 재강조.
Trigger 08 · 한정 자격
🎯"2025년생 한정"
Frame C · 정책 태그
1.0 이자지원은 2025-01-01 이후 출생 한정 — 실제 조건. "지금 자격이 있는 나"라는 희소성 인식이 "이 타이밍을 놓치면 안 된다"를 만듦.
Trigger 09 · 공유 압력
💛"친구 3명이 보는 중"
Frame C · 공유 FAB
공유 버튼에 또래 행동 신호를 붙여 호혜성·소속 욕구 자극. 공유가 "광고"가 아니라 "나도 동참" 행동이 됨 → 바이럴 계수 K 상승.
윤리 가드레일. 모든 긴박 장치는 실제 사실에만 건다 — 마감일은 진짜 모집 공고일, "2025년생 한정"은 진짜 자격 조건, 금액은 검증된 정책 합산. 가짜 카운트다운·허위 재고·조작된 숫자는 쓰지 않는다. 제품 가치(진짜 무료 지원금)가 진짜라서, 긴박함도 정직하다. 이것이 다크패턴과 갈리는 지점.
