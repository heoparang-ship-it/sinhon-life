신혼생활 v4 — 지원금 카테고리

홈 "지금 많이 찾는 정보"에 지원금 진입 → 삼쩜삼식 라이브 카운터 → 카카오 게이트 → 결과

👆 홈의 파란 "지원금" 카드를 눌러 시작 · 옵션 누르면 숫자 차오름 · "나중에 할게요"도 동작
설계 요약 — 진입점 + 카카오 게이트 3규칙
  • 진입: 홈 "지금 많이 찾는 정보" 안에 지원금 와이드 카드(파란 강조). 같은 섹션이라 발견 쉽고, 광고/공유는 이 화면으로 바로 착지 가능.
  • 게이트 위치: 숫자를 끝까지 본 직후 "정확히 보기" 자리 = 욕망 정점. 삼쩜삼과 동일.
  • 규칙 ① 예상 금액·정책은 무가입으로도 보임("나중에 할게요" → 결과 진입). 막다른 길 X.
  • 규칙 ② 가입 이유를 사용자 이익으로(정확한 금액·마감 알림·저장). "회원가입하세요" X.
  • 규칙 ③ 게스트는 핵심 2개만 보이고 나머지 잠금 → 가입 동기. 단 가치는 이미 충분히 줌(다크패턴 회피).
  • 가입(정확히 보기)과 공유(친구 보내기)는 다른 화면·다른 버튼으로 분리 — 한 번에 한 행동.
