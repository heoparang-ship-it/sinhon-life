- **상세 타겟 확장**: 끔 (1단계 학습 정확도)

## 5. 3일 점검 KPI

| 지표 | 목표(일) | 비고 |
|---|---|---|
| Impressions | 5,000~15,000 | 인천 단일 지역이라 CPM 낮음 |
| Link Clicks | 100~300 | CTR 2%+ |
| CPC | 100~400원 | 200원 이하면 매우 좋음 |
| Landing Page View | 클릭의 80%+ | LCP 빠르면 90% |
| 자가진단 완료(Lead) | 페이지뷰의 15%+ | Pixel `Lead` 이벤트 |
| 정책 상세 진입 | 자가진단의 50%+ | `ViewContent` |
| CPL(자가진단당 비용) | 1,000~3,000원 | 1,500원 이하면 즉시 증액 |

**평가 시나리오 (4일차 아침)**:
- CPL ≤ 1,500원 → 일예산 3배로 증액 + 승자 광고세트에 몰빵
- CPL 1,500~3,000원 → 광고 크리에이티브 1~2개 교체, 예산 유지
- CPL > 3,000원 → 타겟 재정의 (관심사 좁히기) 또는 카피 전면 교체
- CTR < 1% → 소재가 매력 부족. 이미지 우선 교체

## 6. 사장님 셋업 체크리스트 (광고 ON 30분 전)

> 모두 환경변수로 동작. 비어 있으면 코드는 안전하게 노옵.

### ✅ Meta 측 (Ads Manager)
1. **Business Manager** 광고계정 결제수단 확인 (한도 0이 아닌지)
2. **Meta Pixel** 만들기 → ID 복사 (15~16자리 숫자)
   - Events Manager → 데이터 소스 → Pixel 만들기
3. **도메인 인증** sinhon.life — Business Settings → 브랜드 안전성 → 도메인
4. **iOS 14+ 8개 이벤트** 우선순위 설정 (`PageView`, `ViewContent`, `Lead`, `CompleteRegistration` 포함)

### ✅ Vercel 환경변수 (Project Settings → Environment Variables)
- `NEXT_PUBLIC_META_PIXEL_ID` = 위 Pixel ID (필수)
- `NEXT_PUBLIC_GA_ID` = G-XXXX (있으면)
- `NEXT_PUBLIC_POSTHOG_KEY` = phc_… (있으면)

(운영자 알림은 트래픽 모으기 다음 단계 — 리드 들어오면 그때 세팅)

### ✅ QA (광고 ON 직전 5분)
1. 시크릿창에서 광고 URL 열어보기 (UTM 포함)
2. 자가진단 1회 완료 → 결과 화면 확인
3. 브라우저 개발자도구 Network 탭에서 `fbevents.js` + `tr?id=...&ev=Lead` 호출 확인
4. Meta Events Manager의 **Test Events** 탭에서 자기 디바이스로 테스트 이벤트 발화 확인
