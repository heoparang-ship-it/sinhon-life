## ★ 첫 페이지 (평가자 60초 룰) — 모든 서류 맨 앞

**과제명**
> 「**국내 최초, 청년 신혼부부의 결혼준비 의사결정을 'Choice Share(같은 선택 비율)' AI로 돕는 인천 기반 하이퍼로컬 플랫폼 '신혼생활'**」
> *국내최초 방어범위: 단순 후기·견적 중개나 수기 컨설팅이 아닌 「유사 코호트의 실제 선택 비율을 산출·노출하여 확신을 부여하는 의사결정 AI」 결합에 한정.*

**한 문장 정의**
> 900만~3억 원 견적이 난무하는 깜깜이 웨딩 시장에서, **"나와 비슷한 신혼들이 무엇을 얼마에 선택했는지"**를 AI가 보여줘 결정의 확신을 주는 서비스. 인천 부평·송도부터.

**서비스 흐름**
> 영상·검색(유입) → 온보딩 2질문(결혼시기·지역) → AI톡이 5대 결정점 의사결정 가이드 → **Choice Share + 파트너 매칭** → 카카오 알림톡 리드 → 만족도 학습(👍/👎) → 재개인화

**핵심 문제 (근거)**
- 2025년 혼인 **24만 건(+8.1%, 3년 연속 증가)** — 시장 타이밍 ↑ (통계청)
- 결혼서비스 평균 **2,139만 원**, 동일 스드메 견적 **900만~3억** (한국소비자원 2026.2) → 정보 비대칭·깜깜이 가격이 결혼비용 부담의 핵심.
- 신혼부부는 **"무엇을 얼마에 정할지" 결정 불안** → 플래너 의존 → 수수료 불투명 → 비용 폭증의 악순환.

**차별성 (한 줄)**
> 기존은 업체·후기 '나열'(결정은 소비자 몫). 우리는 **"같은 선택 비율"을 보여줘 결정의 확신을 부여**.

**실행 증거**
> sinhon.life 운영 중(영상 아카이브·공동 가계부·AI톡·👍/👎 측정 인프라) · 의사결정 AI 프로토타입(naratmal 룰엔진+LLM, 인천 정책 DB) 보유 · 인천 부평/송도 시드 시장 컨택 진행.

**정책 적합성 (5중 정합)**
> ① **저출생 대응**(결혼비용 부담 완화) ② **청년 창업**(대표 만 37세·청년 채용) ③ **AI·데이터 전환(AX)** ④ **소비자 정보격차 해소**(사회적 가치) ⑤ **인천 지역경제**(부평·송도 우선) — 어느 한 공고에 가도 최소 3개 동시 충족.

## 4. 개발 목표 및 내용 ★AI 상세

**4-0. 최종 목표** 청년 신혼부부의 결혼준비 의사결정을 **"같은 선택 비율"** 로 확신 부여하는 AI 플랫폼 완성. 인천 부평/송도에서 단위경제 증명 → 전국 확장.

**4-1. 시스템 아키텍처 (5계층 + Choice Share)**

```
[1] 의사결정 프로파일러
    ├ 온보딩(결혼시기·지역)
    ├ 대화 슬롯 추출 (예산·일정·스타일·우선순위)
    └ 가계부 시그널 (큰지출 카테고리 직전)
            ↓
[2] 카테고리 라우터 (5대 결정점)
    sdm · venue · interior · goods · honeymoon
            ↓
[3] 지식·데이터 레이어
    ├ chat_logs (대화·슬롯·추천)
    ├ decision_leads (실제 선택·전환)
    ├ 가계부 (실지출 벤치마크)
    ├ 한국소비자원 시드 (콜드스타트)
    └ 인천 정책 DB (naratmal 흡수)
            ↓
[4] 추천·랭킹 엔진 + ★Choice Share Engine
    ├ 룰엔진(안전·환각방지·결정권)
    ├ 가격 적정성 스코어
    ├ 개인 프로파일 매칭 스코어
    └ Choice Share: 유사 코호트 선택 비율·평균가·신뢰도
            ↓
[5] LLM 대화·설명 + 피드백 학습 루프
    ├ LLM prose만 (안전)
    ├ DecisionLeadCard + Choice Share 배지
    └ 👍/👎·전환 결과 → 가중치 업데이트
```

**6-3. 수익모델 (BM 다각화)**
1. **송객 수수료** (성과형, 5대 카테고리) — 기본
2. **결정시점 네이티브 광고** — "AI 추천 슬롯"에 동의 기반 노출 (검색·푸시 광고 X)
3. **하이퍼로컬 가격지수 SaaS** — "부평 스드메 시세 지수" 업체 구독
4. **신혼 큐레이션 패키지** — 정찰가 묶음 판매, GMV 수취
5. **데이터 인사이트 판매** (후행·익명화) — 가전·가구 브랜드향

**6-4. 초기시장 침투전략 — 하이퍼로컬 시드**
- **Phase 0 (1~3개월)**: 부평구 한정. 메타광고 + 인스타 + 부평 스튜디오 10곳 직접 컨택. CAC 최소화.
