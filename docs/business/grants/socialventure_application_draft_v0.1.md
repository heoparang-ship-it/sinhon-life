## 1. 사회적 미션 (Mission)

**한 문장 미션**
> "결혼비용 정보 비대칭으로 인한 청년 신혼부부의 의사결정 불안과 비용 폭증을 **'같은 선택 비율'을 보여주는 AI**로 해소하여, **저출생 시대의 결혼 진입 장벽을 낮춘다.**"

**왜 사회적 문제인가**
- 2025년 혼인 24만 건(+8.1%, 통계청) — 결혼은 늘었으나
- 결혼서비스 평균 **2,139만 원**, 동일 스드메 견적이 **900만~3억** (한국소비자원 2026.2)
- 견적 차이의 본질 = **정보 비대칭** → 소비자가 합리적 판단 불가 → 플래너 의존 → 수수료 불투명 → 비용 폭증
- 결혼비용 부담은 **저출생의 직접 원인** 중 하나 (결혼 지연·포기 ↑)
- 청년층(2030)은 정보 격차의 가장 큰 피해자

## 2. 평가지표 3축 자체분석

### 2-1. 사회성 ★

| 사회적 가치 | 내용 |
|---|---|
| 1) 정보 격차 해소 | 깜깜이 웨딩 가격 → "같은 선택 비율"·실지출 데이터 공개로 정보 비대칭 직접 해소 |
| 2) 저출생 대응 | 결혼비용 부담 완화 = 저출생 진입 장벽 완화 (국가 최우선 과제 직접 기여) |
| 3) 청년 보호 | 청년 신혼이 정보 부족으로 과다 지출하지 않도록 보호 (소비자권익) |
| 4) 청년 일자리 | 청년 대표(만 37세) + 신규 채용 청년 우선 |
| 5) 지역경제 | 인천 부평·송도 시드 → 지역 결혼산업 디지털 전환 |
| 6) 데이터 투명성 | "샘플 ○명 기준" 정직 라벨 + 코호트 신뢰도 공개 (자기실현 편향 방지) |

**측정 가능한 사회적 성과 지표 (KPI)**
- 사용자 평균 결혼비용 절감 효과 ([목표]% 감소)
- 의사결정 만족도 (👍 비율 ≥70%)
- 인천 지역 신혼 도달 사용자 수
- 청년 정보격차 해소 사용자 수
- 청년 고용 창출 인원

### 2-2. 혁신성

| 항목 | 내용 |
|---|---|
| 1) 핵심 기술 | **Choice Share Engine** — 유사 코호트(지역·예산·시기·취향) 선택 비율·평균가·신뢰도 산출 AI |
| 2) 아키텍처 | 5계층(프로파일러 → 카테고리 라우터 → 데이터 → 추천+Choice Share → LLM+학습루프) |
| 3) 데이터 차별성 | 챗 대화 + 실지출(가계부) + 영상 탐색 + 실제 선택 결과 = 4중 데이터 학습 |
| 4) 안전장치 | LLM 분리(prose만) + 룰엔진 결정권 + 콜드스타트 정직 라벨(샘플<5 시 명시) |
| 5) 국내 최초성 | "유사 코호트 선택 비율 노출로 결혼 의사결정 확신 부여"하는 AI 서비스 부재 |
| 6) IP 출원 | 특허 가출원 준비 (`docs/business/ip/patent_provisional_v0.1.md`) |

### 2-3. 성장성

| 단계 | 시기 | 핵심 |
|---|---|---|
| 시드(인천 부평) | 1~3개월 | 단일 구 시장에서 단위경제 증명 |
| 시드 확장(송도) | 3~6개월 | 동일 모델 복제로 확장성 검증 |
| 인천 전역 + 5대 카테고리 | 6~12개월 | 카테고리 라우터 풀가동 |
| 수도권·전국 | 12~24개월 | + B2B 가격지수 SaaS |
| 글로벌 (대만·일본·베트남) | 24개월+ | 저출산·고비용 웨딩 문화권 복제 |

- TAM 약 5.1조 원/년 (24만 쌍 × 2,139만)
- SOM(부평 시드) [확인필요]
- BM 다각화 5종 (송객 + 광고 + 가격지수 SaaS + 큐레이션 패키지 + 데이터 인사이트)
